## 这套文件是什么、不是什么

- **是**：可以一比一建模的参数化规格。每个零件的尺寸、位置、孔槽特征、所属步骤、放入方向、五金、检查点都由脚本从一张参数表算出。
- **不是**：生产图。标“假设”的数值（X01–X33）没有经过样件验证，只是让模型闭合的合理取值。工厂报价、样件测量或测试结果出来后，改 `params.yaml` 里的对应值，重新运行脚本即可。

## 文件

| 文件 | 作用 |
|---|---|
| `params.yaml` | **唯一的尺寸来源**。每个参数注明来源：原文／决定（D1–D16）／假设（X##） |
| `generate.py` | 从参数表生成全部零件、端口、装配步骤、加装套件，并做自检 |
| `build/model.json` | 生成结果：`configs.{entry,desk,bedside}` 下有 `parts`、`ports`、`steps`、`geo`；另有 `kits`、`retired_paths`、`actions`、`params` |
| `build/cutlist.csv` | 开料清单（UTF-8 带BOM，可直接用Excel打开） |
| `build/checks.md` | 自检报告：总高链、干涉、入槽深度、板件数对账、步骤覆盖、稳定性粗算、端口引用 |
| `viewer/template.html`、`viewer/build_viewer.py` | 拼装动画页面模板与注入脚本 |
| `build/assembly_viewer.html` | 生成的逐步拼装动画页（three.js r128） |

运行：

```bash
pip install pyyaml
python3 generate.py            # 生成 build/ 下的 model.json、cutlist.csv、checks.md
python3 viewer/build_viewer.py # 生成 build/assembly_viewer.html
```

## 坐标系与单位

- x：宽度方向，左→右；y：深度方向，**前(0)→后**；z：高度方向，地面(0)向上。
- 原点：主体前沿左下角在地面上的投影。加宽底座向前伸出，所以底座的 y 为负（−200）。
- 单位：毫米、公斤、牛。
- 每个零件的 `pos` 是包围盒最小角，`size` 是包围盒尺寸（x×y×z，即宽×深×高）。
- 倾斜件（目前只有鞋斜板 `SHOE`）另带 `rot: {axis: "x", deg: 15}`，`size` 是倾斜后的包围盒；实际板件为 562×300×18，绕 x 轴转 15°，前低后高。
- 换到 three.js（y 朝上）：`three.x = x`，`three.y = z`，`three.z = −y`。

## 零件数据结构（model.json → configs.*.parts[]）

```json
{"id": "SL", "name": "F1200整高竖板（左）", "kind": "board", "group": "结构板",
 "material": "桦木胶合板", "size": [18, 400, 1200], "pos": [0, 0, 60], "mass": 5.88,
 "features": [{"type": "groove", "width": 13.0, "depth": 8, "y_from": 377.5, "y_to": 390.5, "z_from": 0, "z_to": 1200, "face_x": 18},
              {"type": "hole", "dia": 5, "depth": 10, "face_x": 18, "y": 37, "z_list": [64, 96, ...]}]}
```

- `kind`：board（胶合板）、metal（钢／铝）、accessory（自家配件）。
- `features` 的坐标都相对零件自身的 `pos`。孔、槽、嵌件、连接片都列在这里。
- `ports` 是冻结的出厂端口（D8），加装套件只能引用这些端口，用户不钻孔。

## 装配步骤（model.json → configs.*.steps[]）

```json
{"id": 6, "title": "面板1：从顶端滑入两侧后槽，落到底", "action": "A2",
 "parts": ["PNL1"], "from_offset": [0, 0, 1400], "fasteners": [], "tool": "无", "people": 2,
 "check": "面板落底有“嗒”声；一人扶竖板顶端", "precondition": "顶盖尚未安装"}
```

- `parts`：这一步放入的零件编号。每个零件只在一个步骤里出现；`checks.md` 会核对是否有遗漏。
- `from_offset`：动画起点相对最终位置的偏移（mm，同一坐标系）。`[0,0,1400]` 表示从上方落下，`[0,-400,0]` 表示从正面推入，`[±300,0,200]` 表示从侧面立起。
- `action`：引用原文动作库 A0–A17（名称在 `actions` 里），带 `*` 表示本规格对该动作的延伸用法。
- 页面动画只读这些字段，不含任何尺寸常量。

## 建模时要守的规则

1. **只改 `params.yaml`**，不在脚本或页面里写死尺寸。改完运行脚本，看 `checks.md` 是否全部通过。
2. 1.2米及以上的挂物件必须用加宽底座（约600深）＋配重，并随货附防倾固定件（D13）。300深只能在固定时使用。
3. 低位块最多叠3层，第3层附防倾固定件（D14）。F整高竖板不能拆层。
4. 不用18毫米板直接钻Ø5孔做挂载；挂载面用方案b（间隔薄穿孔面）或方案a（锁定挂钉），由样件比较决定（D6）。
5. 大面先按白色层压饰面桦木胶合板建模，与白漆样板对比（D15）；强调色只用在配件和加装件上（D10）。
6. 铝只出现在可选铝轨、护边选项和备用骨架上（D5）。

条件：前挂10公斤、重心在挂载面前80毫米、1.1米高处向前水平拉；只算静力矩，不含摩擦、冲击和脚垫变形。**不能代替测试。**

## 还没解决、不能靠建模解决的

- 挂载面方案a／b的选择（D6样件比较）。
- 白漆与白色层压饰面的选择（D15样板）。
- 侧向晃动、拉力、湿度（新加坡年均约84%）下的实测。
- 工厂报价与开料余量（X系列值会随报价调整）。
- 定价（D16：设计导向、几百新元一档，靠报价和带价格的访谈验证）。
